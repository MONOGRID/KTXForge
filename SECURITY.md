# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities privately via [GitHub Security Advisories](https://github.com/MONOGRID/KTXForge/security/advisories/new).

Do **not** open a public issue for security reports.

You can expect an initial response within **7 days**. If the report is accepted, we will work with you on a fix and coordinated disclosure. If it is declined, we will explain why.
